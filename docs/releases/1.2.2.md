## Ice and Fire changes

Owned dragons receive terrain corrections for movement, breath, charges, and explosions; Cyclops tree breaking, Sea Serpent vegetation breaking, and Death Worm explosion terrain are also covered. Wild behavior remains native. The newer IAF ports use scoped terrain hooks rather than broadly denying DragonBase grief events, preserving the native charge area-damage path.

Dragon color and growth stage identify forms. Captured age/size is retained in previews and aging is disabled after summon/reload. Soul dragons use the core API's **100-block** Follow/Aggressive owner range and a neutral detached GUI pose. Hydra preview data includes head count and severed-head state. Summoning resets inherited death/sitting/breath/home/crystal-binding state and reassigns an already tamed dragon to the summoner.

The 1.16.5 development profile normalizes three verified Dread scale-forwarder mapping collisions in a separate ignored dependency copy. Original mod JARs stay unchanged, and playtest archives use original distribution dependencies. Creature-mod code/assets are not bundled.

## Twilight Forest changes

Extend exact-creator ownership to Ur-Ghast ghastlings, Swarm Spider offspring, and Tower/Carminite Broodlings, alongside Snow Queen ice crystals and Lich descendants. Native spawn conditions/limits remain; nearby unrelated creatures are not adopted. Ur-Ghast's native spawn-site hook covers summons triggered outside its ordinary tick.

Native master restoration, orphan searches, and clone cleanup respect each root/player lineage and remain separate from wild encounters. The old Lich minion constructor/type correction is **1.16.5-only**; upstream already fixes it on 1.19.2/1.20.1.

## Setup and branding

Install core and addon on both client and server with version-matched creature mods/libraries. The addon consumes an installable core JAR rather than an adjacent checkout:

```properties
soulcatcherplusJar=C:/Minecraft/mods/soulcatcherplus-1.2.2+1.16.5.jar
```

Put the path in ignored `local.properties`, or override it with `-PsoulcatcherplusJar=<path>`. The build checks core metadata/version. Legacy ports use content-hashed `fg.deobf`; 26.3 uses the unobfuscated JAR through `implementation files(coreJar)`. The [README](../../README.md) provides bootstrap/IDE/build/run instructions.

The approved transparent `art/branding/logo-banner-compat-v2.png` supplies the right-aligned cyan COMPAT banner. Retain approved source/runtime assets; unused drafts and generated outputs stay local. Both projects now target Forge **66.1.0** on 26.3; historical artifacts keep their original requirements. No universal mod or world-migration compatibility is promised.
