# Soul Catcher Plus Compat 1.3.0.1

Release date: **2026-11-26**. This maintenance release accompanies
[Soul Catcher Plus](https://github.com/1PixelDemon1/soul-catcher-plus) 1.3.0.1 on
four Forge platforms. Fresh builds, archive audits, and installed-client startup
checks passed.

| Minecraft | Forge build target | Declared Forge minimum | Game Java | Addon version |
|---|---|---|---|---|
| 1.16.5 | 36.2.42 | **36.2.26** | 8 | `1.3.0.1+1.16.5` |
| 1.19.2 | 43.5.0 | 43.1.10 | 17 | `1.3.0.1+1.19.2` |
| 1.20.1 | 47.4.28 | 47.1.4 | 17 | `1.3.0.1+1.20.1` |

## Changes and installation

- Raise the 1.16.5 Forge runtime floor from 36.0.42 to **36.2.26**, matching the
  core correction. The build target remains 36.2.42; the other ports keep their
  existing build targets/minima.
- Accept matching-Minecraft core **1.3.0.1**, **1.3.0**, or **1.3.0-prerelease**.
  Stable 1.2.3 users retain Compat 1.2.3. Existing integrations/terrain protection
  remain unchanged.
- Order those exact version alternatives for Forge's Maven range parser. Checks
  using each minimum Forge profile's Maven implementation accept all three intended
  versions and reject a different Minecraft version.
- Pair with the core's corrected no-argument entrypoint on 1.20.1. This is a core
  loader fix, not a new addon gameplay feature.

Install matching Minecraft core/addon runtime JARs on both sides, with creature
mods and their libraries separately. The addon bundles neither core nor third-party
classes/assets. Creature integration and Forge Patchouli availability on 26.3
remain unverified; wider metadata ranges do not certify every dependency release.

Standalone development still uses an installable core runtime JAR configured via
`soulcatcherplusJar` in ignored `local.properties` or its `-P` override. For example:

```properties
soulcatcherplusJar=C:/Minecraft/mods/soulcatcherplus-1.3.0.1+1.16.5.jar
```

No adjacent core source checkout is required. Historical releases/tags retain
their original requirements and artifacts.

## Artifacts and validation

Files are `soulcatcherplus-compat-1.3.0.1+<minecraft>.jar` and matching sources
JARs for all four platforms; install runtime JARs only. The prepared addon set
includes four runtime JARs, four sources JARs, and `SHA256SUMS.txt`.

All eight fresh core/addon `build -x test` runs and 16 runtime/sources archive
audits passed. Metadata/core acceptance, Forge minima, class levels 52/61/61/69,
JSON/Mixin resources, and isolation were checked. The native Maven range
implementation from each minimum Forge profile accepts all three intended core
versions and rejects a different Minecraft version.

A fresh **26-run installed-client matrix** verified exact **1.3.0.1 release bytes**
across 13 Minecraft/Forge combinations, using core alone and core plus Compat,
without optional creature mods or worlds. All passed startup and normal closure
with exit 0. Forge sets were 36.2.26/36.2.34/36.2.42,
43.1.10/43.5.0/43.5.2, 47.1.4/47.2.5/47.4.28/47.4.29, and
66.0.0/66.1.0/66.1.9 for the respective platforms.

A separate isolated **OccultCraft** copy on Minecraft 1.20.1 / Forge 47.2.5 also
passed startup and normal exit 0 with both exact final JARs, without entering a
world. The earlier 1.3.0-versioned 26-run audit remains separate historical
evidence; it was not substituted for these fresh checks.

No new dedicated-server checks, automated tests, GameTests, UI automation,
gameplay, combat, or multiplayer verification ran. Startup does not establish
universal modpack, attack/terrain, or dependency-version compatibility.
