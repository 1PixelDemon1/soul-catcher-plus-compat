## Installation and changed behavior

Install the Minecraft-specific core and addon on both client and server. The addon requires its exact matching core version. Creature mods/libraries are optional separate installations, not bundled code/assets. Use separate Minecraft profiles/worlds and remove duplicate old JARs. The new 1.19.2 target/minimum is Forge 43.5.0; 1.20.1 remains 47.4.28. Existing artifacts, historical notes, and release tags keep their original baselines.

The dedicated Ferrous Wroughtnaut activation/appearance adapter and soul-profile override are removed. Wroughtnaut uses generic core behavior plus the retained Mowzie area-attack ally filter. This does not certify every native phase or animation through generic behavior.

Twilight Forest corrections attribute Snow Queen ice crystals and restore native Lich clone/minion master links. Aquamirae corrections suppress identifiable companion Cornelia music and preserve the ordinary encounter's shared cooldown. The 1.20.1 correction targets inspected 6.x controllers; Aquamirae 7.x is not verified.

## Standalone development and runtime

Configure an installable core JAR in ignored `local.properties`, for example:

```properties
soulcatcherplusJar=C:/Minecraft/mods/soulcatcherplus-1.2.0+1.16.5.jar
```

The file must exist and declare the branch's expected core ID/version. `-PsoulcatcherplusJar=<path>` overrides this setting. Select the runtime core for the matching Minecraft version, not its sources JAR or the addon. Legacy projects deobfuscate a content-hashed local dependency through `fg.deobf`; 26.3 consumes the unobfuscated JAR using `implementation files(coreJar)`. No adjacent core source checkout is needed or rebuilt automatically.

1.16.5 uses Java 17 for Gradle/javac plus Java 8 runtime; 1.19.2/1.20.1 use Java 17; 26.3 uses Java 25. The matching branch's bootstrap/wrapper prepares/selects its tooling. Import the Gradle project into the IDE after setting `local.properties`; the declared dependency supplies core classes and the development runtime. Build/run commands and exact portable examples are in the [README](../../README.md).

## Integration baselines and availability

| Minecraft | Mowzie API baseline | Twilight Forest baseline | Aquamirae API baseline |
|---|---|---|---|
| 1.16.5 | 1.5.27 | CurseForge file 3575220 | 5.4.API11 / Obscure API 11 |
| 1.19.2 | 1.6.3 | 4.2.1518 | 6.API15 / matching Obscure API 15+ |
| 1.20.1 | 1.8.2 | 4.3.2508 | Inspected 6.1.2 and 6.4.0 controllers |
| 26.3 | No verified creature-mod runtime | Official Forge 26 build not verified | No verified creature-mod runtime |

For 26.3, the release's Modrinth lookup identified no Forge releases of Mowzie's Mobs, Aquamirae, or Patchouli. An official Twilight Forest Forge 26 build was not verified. The addon is therefore a **build/load baseline with the core alone**, not verified support for those integrations. Do not install older Minecraft creature-mod JARs on this basis. The optional Patchouli guide belongs to the core and is available on the older three supported versions, not claimed for 26.3.

Source/API baselines and optional metadata ranges are not universal compatibility certification. Each creature mod's own matching libraries must be installed separately.

The core separately passed three persistence JUnit checks on each of 1.19.2/1.20.1/26.3, plus its own client/core-server checks as recorded in its release notes. Those results do not test addon integrations. Creature-mod support on 26.3 remains limited by unverified availability. Packaged artifact identities/checksums belong with the final local distribution.
