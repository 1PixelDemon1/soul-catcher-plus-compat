## Owned Siren appearance and charm

Owned Ice and Fire Sirens keep their normal appearance while idle or chasing.
Their monster appearance is shown during the native **BITE/PULL attack animations**
(20 ticks), rather than remaining active throughout combat. The appearance hook
is client-side; native server attack behavior is preserved. Summoning clears
inherited aggression/singing state before normal companion behavior takes over.

An owned Siren cannot charm its owner or allied companions. This prevents that
friendly source's charm-driven pink overlay, forced approach, and jump-scare
sequence. Existing charm is cleared when its source is that same owned allied
Siren. Wild/hostile Siren charm and unrelated charm sources are not globally
disabled.

The 1.16.5/1.19.2 hook guards native `SirenProperties`. On 1.20.1 the matching
`SirenData.tickCharmed` hook runs after lazy owner restoration and before singing
effects/data synchronization, allowing restored friendly charm to be cleared at
the correct point in the newer lifecycle.

## Installation and standalone setup

Install matching core/addon JARs on both client and server, with selected creature
mods and their libraries separately. The addon requires the exact core version
and bundles neither the core nor third-party classes/assets.

Configure an installable core JAR in ignored `local.properties`, for example:

```properties
soulcatcherplusJar=C:/Minecraft/mods/soulcatcherplus-1.2.3+1.16.5.jar
```

The command-line `-PsoulcatcherplusJar=<path>` overrides it. Legacy branches use
content-hashed `fg.deobf`; 26.3 consumes its unobfuscated JAR directly. No adjacent
core source checkout is required. The [README](../../README.md) documents toolchains,
bootstrap, IDE import, and build/run commands. Approved banners and historical
release records remain intact.
