# Project branding

User-supplied original PNGs, adopted for the next release after 1.1.0.

- `logo-banner.png`: logo with the Soul Catcher Plus lettering. Use for GitHub
  presentation and other banner placements.
- `logo-icon.png`: symbol without lettering. Use for mod branding, icons,
  avatars and other placements that do not require a banner.

Keep both originals unchanged, including their transparency. Create derived
copies at the required dimensions when integrating the next release. Preserve
the artwork and aspect ratio; use nearest-neighbor scaling for pixel-art copies.

These assets are staged for the next release. The existing 1.1.0 release files
and tag retain their original artwork.
